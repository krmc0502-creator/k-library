# K.Library

本との出会いを大切に残す、自分専用の読書アプリです。
iPhoneのホーム画面に置いて使うWebアプリとして作っています。

- 本の記録はiPhoneの中だけに保存され、このページの置き場所には送られません。
- 費用はかかりません（GitHub Pagesで公開）。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| index.html | 画面の中身（何をどの順に並べるか） |
| style.css | 見た目（色・大きさ・余白） |
| app.js | 動き（あいさつや季節のひとことを変える） |
| manifest.webmanifest | ホーム画面に追加したときの名前やアイコン |
| sw.js | 電波がないときも開けるようにする係 |
| images/ | ヘッダーの絵とアイコン |
